Turn access logs into answers

A zero-dependency Rust CLI that streams nginx and Apache logs and reports top routes, status codes, IPs, 404 hot spots, bot traffic and requests per hour, as a terminal dashboard or JSON.

View sourceRun it locally

Highlights

Zero-copy parsing

Entries borrow slices of each line, so parsing allocates nothing.

Constant memory

Streams any BufRead line by line; pipe in gigabytes from zcat.

Useful signals

5xx rate, bot share, and the 404s scanners and broken links hit most.

Script friendly

--json output with proper string escaping, --status filter, multiple files.

Robust

Malformed lines are skipped and counted, never a panic.

Strict CI

rustfmt, clippy -D warnings, unit and end-to-end tests.

Run it

Run

git clone https://github.com/Lekopien/rust-log-analyzer
cd rust-log-analyzer
cargo run --release -- samples/access.log
